# coercion.md — 类型归一

归一发生在校验之前、`default` 写入之前。归一只作用于标量字段，
不改对象的键名，不改数组的结构（数组的归一递归到元素）。

## §1 原则

- 归一只在目标 `type` 明确时发生。没有 `type` 的字段保持原样。
- 归一只把「无损、唯一」的字符串转成目标类型。任何有歧义、有损、
  或超出目标类型可表示范围的输入都**不转**，字段保持原字符串，
  由后续类型校验决定它是否合法。
- 归一不能改变语义。`"01"` 和 `"1"` 不是同一个整数；`"1e400"` 不是有限数。

## §2 逐类型对照表

| 目标类型 | 输入 | 结果 |
|---|---|---|
| `integer` | `"12"` | `12` |
| `integer` | `" 12 "` | 保持 `" 12 "`（前后空白不剥离） |
| `integer` | `"12abc"` | 保持 `"12abc"`（不是前缀解析） |
| `integer` | `"0x10"` | 保持 `"0x10"`（不认十六进制） |
| `integer` | `"012"` | 保持 `"012"`（前导零不归一） |
| `integer` | `"-3"` | `-3` |
| `integer` | `"1.0"` | 保持 `"1.0"`（整数字面量才转） |
| `integer` | `12.0`（JSON number） | `12`（已是整数值） |
| `integer` | `12.5` | 保持 `12.5`，交由校验拒绝 |
| `number` | `"1.5"` | `1.5` |
| `number` | `"1e400"` | 保持 `"1e400"`（不是有限数） |
| `number` | `"Infinity"` | 保持 `"Infinity"` |
| `number` | `"12abc"` | 保持 `"12abc"` |
| `number` | `"0x10"` | 保持 `"0x10"` |
| `number` | `" 1.5 "` | 保持 `" 1.5 "` |
| `number` | `"1_000"` | 保持 `"1_000"` |
| `boolean` | `"true"` | `true` |
| `boolean` | `"false"` | `false` |
| `boolean` | `"TRUE"` / `"True"` / `"FALSE"` / `"0"` / `"1"` / `"yes"` | 保持原字符串 |
| `string` | 任意标量 | 不转换（数字不转字符串） |
| `null` | `"null"` | 保持 `"null"` |
| `array` | 单值 `x` | 保持 `x`，**不**包成 `[x]` |

布尔只认全小写的两个字面量 `"true"`、`"false"`。`"FALSE"` 之类既不能
被当成 `false`，也不能被当成字符串直接放行——它保持字符串身份，
交给 `type: boolean` 的校验去拒绝。

## §3 数字的判定

一个字符串能被当成整数，当且仅当它匹配 `^-?(0|[1-9][0-9]*)$`。

能被当成数，当且仅当它匹配 `^-?(0|[1-9][0-9]*)(\.[0-9]+)?([eE][+-]?[0-9]+)?$`
且解析结果是有限数。`Number.isSafeInteger` 之外的整数、`Infinity`、
`NaN` 都不算。

## §4 `default`

`default` 写在字段缺省时生效。它写入的是**归一后的副本**，
不是 schema 里那个 `default` 对象本身的引用。

`default` 只为 `properties` 里声明过的字段写入。`additionalProperties`
为 `false`（含缺省，见 dialect §1.4）时，`default` 里的未声明键一律不写。

## §5 归一与下游

归一的产物是一份新实例。校验用的实例和最终交给下游的实例不能是同一个
对象引用：下游对实例的任何修改都不能反向影响网关的校验结论，反过来，
网关的归一也不能在调用方持有的对象上留下痕迹。
