# Field map

Status: authoritative. This table is the whitelist of fields the query API
accepts. Do not edit this file; it is the reference every rule in
`docs/query-rules.md` points at.

`column` is the physical column in the `items` table. `sortable` says whether
the field may appear in a sort key.

| field        | column       | sortable |
| ------------ | ------------ | -------- |
| `id`         | `id`         | yes      |
| `name`       | `name`       | yes      |
| `status`     | `status`     | yes      |
| `amount`     | `amount`     | yes      |
| `owner`      | `owner`      | yes      |
| `created_at` | `created_at` | yes      |
| `tags`       | `tags`       | no       |
| `note`       | `note`       | no       |

A field marked not sortable can still be filtered on; it just cannot be used
in `sort`.
